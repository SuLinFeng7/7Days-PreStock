# 智能股票预测系统 (Stock Price Prediction System)

基于深度学习的股票价格预测系统，集成 LSTM、CNN 和 Transformer 三种深度学习模型，支持 A 股和美股的未来 30 天股价预测。

## 功能特点

- 支持多个市场的股票预测（A 股和美股）
- 集成三种深度学习模型（LSTM、CNN、Transformer）
- 提供最长 30 天的未来股价预测
- 可配置 1-10 年的历史数据训练
- 自动生成预测报告和可视化图表
- 提供模型性能评估指标（MAPE、RMSE、MAE）
- 直观的图形用户界面
- 支持批量预测功能
- 自动处理异常值和缺失数据
- 动态学习率调整
- 多尺度特征提取
- 突发事件检测处理

## 模型架构

### 1. LSTM 模型 (V2.0)

- 多尺度注意力机制
  - 不同尺度的卷积核(1x1, 3x3, 5x5)提取特征
  - 自适应权重分配
  - 注意力分数计算和合并
- 突发事件检测层
  - 基于 Z-score 的异常检测
  - 动态阈值调整
  - 事件特征增强
- 连续性正则化
  - 平滑因子动态调整
  - 相邻时间步差值控制
- 参数配置：
  - 隐藏层维度: 128
  - 网络层数: 3
  - Dropout 率: 0.2
  - 批次大小: 32
  - 学习率: 0.001
  - 优化器: Adam
  - 损失函数: Huber Loss
  - 梯度裁剪阈值: 0.5

### 2. CNN 模型 (V2.1)

- 多尺度卷积结构
  - 三个并行卷积分支(kernel_size=1,3,5)
  - 每个分支 128 个滤波器
  - 批归一化和 ReLU 激活
- 残差连接
- 全局平均池化
- 参数配置：
  - 卷积核数量: 128
  - Dropout 率: 0.3
  - 批次大小: 32
  - 学习率: 0.001
  - 优化器: AdamW
  - 权重衰减: 0.01
  - 损失函数: Huber Loss

### 3. Transformer 模型 (V2.0)

- 多尺度特征提取
  - 四个并行卷积分支(kernel_size=1,3,5,7)
  - 特征融合和层归一化
- 自适应注意力机制
  - 动态权重分配
  - 多头注意力聚合
- 突发事件处理
  - 基于移动平均的异常检测
  - 注意力权重动态调整
- 位置编码
  - 正弦余弦位置编码
  - 位置信息增强
- 参数配置：
  - 模型维度: 128
  - 前馈网络维度: 512
  - 注意力头数: 8
  - Dropout 率: 0.15
  - 注意力 dropout 率: 0.1
  - 批次大小: 64
  - 预热步数: 4000
  - 学习率: 0.0001
  - 优化器: AdamW
  - 权重衰减: 0.01
  - 损失函数: Huber Loss
  - 梯度裁剪阈值: 1.0

## 数据处理流程

1. 数据获取与预处理

   - A 股数据通过 Tushare Pro API 获取
   - 美股数据通过 Alpha Vantage API 获取
   - 统一数据格式处理
     - 统一列名(date, open, high, low, close, volume)
     - 统一日期格式为 datetime
     - 统一按日期升序排序
   - 自动处理缺失值(dropna)
   - MinMaxScaler 标准化

2. 特征工程

   - 基础技术指标
     - 移动平均线(MA5/20/60)：使用 rolling 计算
     - RSI 指标：基于价格变动计算相对强弱
     - MACD 指标：基于快慢指数移动平均
     - 布林带：移动平均 ± 标准差
     - KDJ 指标：随机指标计算
   - 高级技术指标
     - ROC(变动率)：价格变化百分比
     - 动量指标：价格差值
     - 波动率：收益率标准差
   - 特征组合：15 个维度特征矩阵

3. 数据增强

   - 添加高斯噪声(noise_scale=0.001)
   - 时间窗口滑动(window_size=20)
   - 原始数据和噪声数据合并

4. 训练集划分

   - 训练集比例: 80%(TRAIN_TEST_SPLIT = 0.8)
   - 验证集比例: 20%
   - 保持时间序列顺序

## 评估指标

- MAPE（平均绝对百分比误差）：衡量预测值与实际值的相对误差
- RMSE（均方根误差）：反映预测的准确性
- MAE（平均绝对误差）：反映预测的平均偏差
- 训练时长统计：记录模型训练耗时
- 预测准确率分析：不同时间尺度的准确率统计
